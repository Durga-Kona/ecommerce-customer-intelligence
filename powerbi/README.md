# Dashboard Options

The project now includes a ready-to-run Streamlit dashboard in `src/dashboard.py`.

Run:

```powershell
streamlit run src/dashboard.py
```

It opens a browser dashboard with KPIs, revenue/profit trends, category analysis, region analysis, payment mix, top products, customer segmentation and business insights.

Power BI can still be used later for the final presentation dashboard. The SQLite database is `ecommerce_dw.db` and the `outputs/` folder contains Power BI-ready CSV exports.
